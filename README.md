# Arif Khan Portfolio — Pro Starter

A responsive one-page portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — main portfolio
- `style.css` — all styles and responsive layouts
- `script.js` — mobile navigation and email enquiry behaviour
- `privacy-policy.html` — starter privacy policy template

## Before publishing
1. The typography has been enlarged for readability on desktop and mobile. The hero currently uses an initials-based visual, not a real photograph. If you want your own photo, add it as `images/arif-khan.jpg` and update the hero/about markup and CSS accordingly.
2. Replace `YOUR_EMAIL@example.com` in `index.html`, `script.js`, and `privacy-policy.html`.
3. Replace the LinkedIn and GitHub links with your real profiles.
4. Change skill descriptions/levels to accurately reflect your current abilities.
5. Replace sample project concepts with your actual projects, or clearly label them as practice/demo work.
6. Remove any service you are not ready to deliver.
7. Review the privacy policy against your actual hosting and tools.
8. Test all sections and the contact form on mobile and desktop.

## Upload to hosting
Upload the files into your hosting's website root (often `public_html` on shared hosting). Keep all four files in the same folder.

## Contact form
The form uses `mailto:` and opens the visitor's email application. It does not submit to a server or store contact details. For direct website submissions, connect a secure backend or trusted form service and update the privacy policy.

## Run locally
Open `index.html` in a browser. Google Fonts require an internet connection; fallback fonts work offline.
